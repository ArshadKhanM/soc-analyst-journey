

## What is a Port?

- **IP Address** → Identifies a device.
- **Port** → Identifies a service.
- **Protocol** → Rules for communication.
## Important Ports

- **20/21 – FTP:** File transfer
- **22 – SSH:** Secure remote login
- **23 – Telnet:** Unsecured remote login
- **25 – SMTP:** Sends emails
- **53 – DNS:** Domain name → IP address
- **67/68 – DHCP:** Assigns IP addresses
- **80 – HTTP:** Web communication
- **110 – POP3:** Downloads emails
- **123 – NTP:** Synchronizes time
- **143 – IMAP:** Email synchronization
- **443 – HTTPS:** Secure web communication
- **445 – SMB:** File sharing
- **3389 – RDP:** Remote Windows desktop
## Cybersecurity Notes 

- **SSH (22)** → Secure
- **Telnet (23)** → Unencrypted
- **HTTP (80)** → Not encrypted by HTTP itself
- **HTTPS (443)** → Encrypted using TLS
- **SMB (445)** → Can be abused by ransomware
- **RDP (3389)** → Can be targeted by attackers
## Remember

- Port **80** = HTTP
- Port **443** = HTTPS
- Port **22** = SSH
- Port **53** = DNS
