1. TCP vs UDP:
- TCP: Reliable protocol that ensures data arrives correctly and in order. 
- UDP: Faster protocol that does not guarantee data delivery.    
- TCP is used in web browsing and file transfers, while UDP is used in gaming and live streaming.

2. TCP Three-Way Handshake
- SYN: Client requests a connection.    
- SYN-ACK: Server accepts the request and responds.
- ACK: Client confirms the connection.
- After these three steps, data transmission begins.

3. Port Number
- A port number identifies a specific application or service on a computer.
- Port numbers range from 0 to 65535.
- Examples: HTTP – 80, HTTPS – 443, SSH – 22, DNS – 53.
