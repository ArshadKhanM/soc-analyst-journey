
### 1. Modem

A modem connects our home network to the internet service provider (ISP). It helps us access the internet.

### 2. Router

A router connects different networks and directs data between them. It allows multiple devices to share one internet connection.

### 3. Switch

A switch connects multiple devices within a local area network (LAN). It sends data to the correct device.

### 4. Access Point (AP)

An access point provides Wi-Fi connectivity to wireless devices. It allows phones, laptops and tablets to connect to a network.

### 5. Firewall

A firewall protects a network by monitoring and filtering incoming and outgoing traffic. It helps block unauthorized access.

### 6. Network Interface Card (NIC)

A network interface card allows a computer to connect to a network. It can support a wired Ethernet or wireless Wi-Fi connection.

### 7. Repeater

A repeater receives and retransmits network signals to extend their range. It helps improve connectivity in areas with weak signals.

Conclusion: All these networking devices work together to provide internet access, connect devices and improve network security.
