### 1. Application Layer

The application layer is the top layer of the OSI model. It provides network services to users and applications, such as web browsing and email.

Protocols: HTTP, HTTPS, FTP, SMTP, DNS.

### 2. Presentation Layer

The presentation layer translates data into a suitable format. It also handles data encryption, decryption and compression.

Examples: JPEG, PNG, ASCII, encryption using TLS.

### 3. Session Layer

The session layer establishes, manages and terminates communication sessions between two devices.

Examples: RPC, NetBIOS.

### 4. Transport Layer

The transport layer delivers data between devices and helps provide reliable communication. It also handles data segmentation and flow control.

Protocols: TCP, UDP.

### 5. Network Layer

The network layer transfers packets between different networks. It uses logical addresses and selects routes to reach the destination.

Protocols: IP, ICMP.

### 6. Data Link Layer

The data link layer transfers data between devices on the same local network. It uses MAC addresses and helps detect transmission errors.

Examples: Ethernet, Wi-Fi (MAC functions), PPP.

### 7. Physical Layer

The physical layer transmits raw bits through physical media such as cables, radio signals and fiber-optic cables.

Examples: Ethernet cables, fiber-optic cables, hubs and repeaters.

## Uses of the OSI Model

- It helps us understand how computer networks work.
    
- It makes network troubleshooting easier.
    
- It helps identify network problems layer by layer.
    
- It provides a standard framework for network communication.
