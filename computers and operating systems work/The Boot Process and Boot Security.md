
**1. BIOS/UEFI:** Firmware that initializes hardware and starts the boot process.

**2. Bootloader:** A program that loads the operating system kernel.

**3. Kernel:** The core of the operating system that manages hardware and system resources.

**4. User Space:** The environment where applications and system services run.

**5. Bootkit:** Malware that attacks the boot process to gain control of a computer and avoid detection.

**6. Secure Boot:** A UEFI security feature that verifies digital signatures of boot software to help prevent unauthorized code from loading.
